# How I categorize spending

A transaction belongs to a category when its description contains one of the
keywords below (ignore upper/lower case).

- groceries: FRESHMART, GREENGROCER, ALDI
- dining: CAFE, PIZZA, SUSHI
- transport: METRO, UBER, SHELL
- utilities: CITY POWER, AQUA WATER, FIBERNET

Spending that matches no keyword goes in `other`.
