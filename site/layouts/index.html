A small coding agent you can understand and make your own.

Give caretz a task and it can inspect a codebase, run sandboxed commands, edit files, and keep working through long sessions. Use local or hosted models, customize its skills and tools, or embed the Go library in your own application.

More than a model wrapper

Small core.
Serious workflow.

Caretz combines the pieces needed for sustained coding work without turning them into a large runtime stack. It is built local-first: it grew from real use with 27B Qwen models on a home RTX 3090, and you can copy the source to an offline machine, build it, and run it against your own GPU. Hosted providers work too, but they never run by accident: model rules keep private directories on local models, and Caretz asks before a cloud model touches a directory no rule covers.

Long-running sessions

Persist, resume, inspect, and repair sessions while repeated compaction keeps limited context useful.

Durable task state

Carry the current goal and next action through compactions so smaller models are less likely to lose the thread.

Skills and subagents

Load project instructions, reusable skills, and focused sequential subagents from plain Markdown.

Tools with guardrails

Choose the file, search, shell, web, image, and integration tools a job needs under the sandbox policy.

Terminal and ACP

Work from the compact terminal UI or connect caretz to editors such as Zed through ACP.

Extensible by design

Strip down the prompt and tools, add custom capabilities, extend the CLI, or embed caretz as a Go library.
